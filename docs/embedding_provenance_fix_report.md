# Embedding Provenance Fix Report

**Date:** 2026-08-28  
**Status:** EMBEDDING PROVENANCE — FIXED

---

## Root Cause Identified

The ingestion log showed:
```
Embedding provider: GeminiEmbeddingProvider
```

Stored embeddings were generated by **Gemini gemini-embedding-2**, but the current runtime uses **Jina jina-embeddings-v3** (because `JINA_API_KEY` is set).

This caused:
- Query embeddings: Jina space
- Document embeddings: Gemini space
- Similarity scores: near zero (0.03-0.05)

---

## Fix Applied

Re-embedded all 226 chunks using the current Jina provider.

| Metric | Before | After |
|--------|--------|-------|
| Chunks re-embedded | 0 | 226 |
| Errors | 0 | 0 |
| Duration | — | 89.7s |
